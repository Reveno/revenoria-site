# Матеріали курсів

Конспекти лекцій, лабораторні та практичні роботи, глосарії термінів.
Матеріали доповнюються протягом навчального року.

## Курси

### [[courses/operating-systems|Операційні системи]]

Від процесів і планування до файлових систем та драйверів.  
*Сторінок: 12*

### [[courses/computer-networks|Комп'ютерні системи та мережі]]

Моделі OSI та TCP/IP, адресація, маршрутизація й налаштування обладнання.  
*Сторінок: 45*

### [[courses/web-programming|Веб-програмування]]

Від HTML і CSS до сучасного JavaScript та інструментів розробника.  
*Сторінок: 25*

### [[courses/neural-networks|Основи штучних нейронних мереж]]

Персептрон, навчання, згорткові та рекурентні мережі.  
*Сторінок: 79*

### [[courses/computer-architecture|Комп'ютерна схемотехніка та архітектура комп'ютерів]]

Логічні елементи, вузли, архітектура процесора й пам'яті.  
*Сторінок: 3*
