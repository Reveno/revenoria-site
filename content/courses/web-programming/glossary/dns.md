# DNS

> [!definition] Визначення
> Domain Name System – розподілена служба, що перетворює доменне імʼя (`example.com`) на IP-адресу сервера через ланцюжок запитів: рекурсивний резолвер → кореневий сервер → TLD-сервер → авторитетний сервер домену.

> [!example] Приклад
> Перше звернення до `example.com` проходить увесь ланцюжок резолвінгу; повторні звернення беруться з кешу, доки не спливе TTL запису.
