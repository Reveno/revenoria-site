# DOM

> [!definition] Визначення
> Document Object Model — деревоподібне представлення HTML-документа в памʼяті браузера, де кожен тег стає окремим обʼєктом-вузлом. Зміна DOM миттєво відображається на екрані.

> [!example] Приклад
> `document.querySelector(".card")` знаходить перший елемент з класом `card`; `element.textContent = "..."` безпечно змінює його вміст.
