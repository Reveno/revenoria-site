# CI/CD

> [!definition] Визначення
> Continuous Integration/Continuous Deployment – автоматичний запуск перевірок (тести, лінтер) при кожній зміні коду (CI) і автоматичне розгортання застосунку після успішного проходження цих перевірок (CD).

> [!example] Приклад
> Workflow GitHub Actions, що запускає `npm test` при кожному pull request і блокує злиття в `main`, якщо тести провалились.
