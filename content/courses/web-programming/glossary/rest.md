# REST

> [!definition] Визначення
> Representational State Transfer – набір архітектурних принципів побудови API: ресурси ідентифікуються через URL (іменники, не дієслова), дії визначаються HTTP-методами, сервер не зберігає стан клієнта між запитами.

> [!example] Приклад
> `GET /courses/42` – отримати ресурс; `DELETE /courses/42` – видалити той самий ресурс тим самим URL, іншим методом.
