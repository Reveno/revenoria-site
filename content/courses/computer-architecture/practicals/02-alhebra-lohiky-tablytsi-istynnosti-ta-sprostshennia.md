# Алгебра логіки: таблиці істинності та спрощення виразів

> [!abstract] Пов'язана лекція
> [[courses/computer-architecture/lectures/02-alhebra-lohiky-bazovi-zakony-ta-operatsii|Лекція 2. Алгебра логіки, базові закони та операції]], [[courses/computer-architecture/lectures/03-lohichni-elementy-and-or-not-nand-nor-xor|Лекція 3. Логічні елементи, AND, OR, NOT, NAND, NOR, XOR]]. Практична робота тренує ключову навичку курсу: перетворювати логічний вираз у таблицю, таблицю у формулу, а формулу у найкоротшу рівносильну форму з обґрунтуванням кожного кроку.

## Мета

Навчитися будувати таблиці істинності, застосовувати закони булевої алгебри (де Моргана, склеювання, поглинання) для спрощення, записувати ДДНФ за таблицею та переходити до базису NAND.

Після заняття ви повинні вміти:

- будувати таблицю істинності виразу з проміжними стовпчиками;
- спрощувати вираз, називаючи на кожному кроці застосований закон;
- записувати ДДНФ функції за таблицею істинності;
- перетворювати вираз у базис NAND і підраховувати кількість елементів.

## Обладнання та програмне забезпечення

- аркуш паперу;
- [CircuitVerse](https://circuitverse.org/) або Logisim-evolution для самоперевірки еквівалентності виразів (за бажанням);
- Python 3: функція перебору всіх комбінацій входів для перевірки.

## Теоретична частина

Закони, потрібні в цій роботі: склеювання $AB + A\overline{B} = A$; поглинання $A + AB = A$; $A + \overline{A}B = A + B$; де Моргана $\overline{AB} = \overline{A} + \overline{B}$, $\overline{A + B} = \overline{A}\,\overline{B}$. Повторюйте їх за [[courses/computer-architecture/lectures/02-alhebra-lohiky-bazovi-zakony-ta-operatsii|лекцією 2]]. Базис NAND розібрано в [[courses/computer-architecture/lectures/03-lohichni-elementy-and-or-not-nand-nor-xor|лекції 3]].

### Зразок розв'язання

Спростити $F = \overline{A}B + AB + A\overline{B}$. Групуємо перший і другий доданки за законом склеювання по змінній A: $\overline{A}B + AB = B$. Отже $F = B + A\overline{B}$. За законом $X + \overline{X}Y = X + Y$ (тут $X = B$, $Y = A$) отримуємо $F = A + B$. Перевірка за таблицею: функція дорівнює нулю лише у рядку 00 ✓.

## Завдання

1. Побудуйте таблицю істинності для $F = \overline{A \cdot B} \cdot (A + B)$. Яку відому функцію вона реалізує?
2. Спростіть, вказуючи закон на кожному кроці: а) $(A + B)(A + \overline{B})$; б) $A + \overline{A}B$; в) $AB + A\overline{B}C$; г) $\overline{\overline{A} + \overline{B}} + \overline{A}$.
3. Доведіть повним перебором закон де Моргана для трьох змінних $\overline{ABC} = \overline{A} + \overline{B} + \overline{C}$.
4. Функція дорівнює 1 на комбінаціях ABC = 001, 010, 100, 111. Запишіть ДДНФ, спростіть, якщо можливо, і назвіть функцію.
5. Перетворіть $F = A\overline{B} + \overline{A}B$ у базис NAND. Скільки елементів NAND потрібно? Накресліть схему.
6. Перетворіть $F = AB + CD$ у базис NAND: двічі заперечте й застосуйте закон де Моргана. Скільки елементів?
7. Охоронна система спрацьовує, якщо ввімкнено охорону **і** (відчинено двері **або** розбито вікно). Запишіть формулу, складіть таблицю істинності та схему.
8. За допомогою Python перевірте еквівалентність виразів із пунктів 2а-2г перебором усіх комбінацій.

### Відповіді для самоперевірки

| Завдання | Відповідь |
|---|---|
| 1 | $F = A \oplus B$ |
| 2а | $A$ |
| 2б | $A + B$ |
| 2в | $A(B + C)$, бо $AB + A\overline{B}C = A(B + \overline{B}C) = A(B + C)$ |
| 2г | $\overline{A} + B$ |
| 4 | $F = A \oplus B \oplus C$ (непарність), мінімізація неможлива |
| 5 | 4 елементи NAND |

> [!warning] Типова помилка
> У пункті 2в є пастка: відповідь не $AB$, а $A(B + C)$. Саме тому вимагається вказувати закон на кожному кроці.
