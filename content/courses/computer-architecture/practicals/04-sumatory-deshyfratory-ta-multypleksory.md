# Суматори, дешифратори та мультиплексори: розрахунок схем

> [!abstract] Пов'язана лекція
> [[courses/computer-architecture/lectures/05-kombinatsiini-skhemy-sumatory-deshyfratory|Лекція 5. Комбінаційні схеми, суматори, дешифратори, мультиплексори]]. Практична робота зводить типові вузли з лекції 5 до кількісних задач: додавання з перенесеннями, віднімання на суматорі, побудова великих вузлів із малих і реалізація функцій на мультиплексорі.

## Мета

Навчитися розраховувати роботу багаторозрядного суматора по розрядах, виконувати віднімання з додатковим кодом на суматорі-віднімачі, будувати дешифратори й мультиплексори з малих блоків та реалізувати логічні функції на мультиплексорі.

Після заняття ви повинні вміти:

- простежити перенесення розряд за розрядом;
- оцінити затримку суматора з послідовним перенесенням;
- зібрати дешифратор 3 → 8 із двох дешифраторів 2 → 4 з дозволом;
- реалізувати функцію трьох змінних на мультиплексорі 4 → 1.

## Обладнання та програмне забезпечення

- аркуш паперу й ручка;
- за бажанням CircuitVerse для самоперевірки схем.

## Теоретична частина

Повний суматор: $S = A \oplus B \oplus C_{\text{вх}}$, $C_{\text{вих}} = AB + (A \oplus B)C_{\text{вх}}$. Віднімання: $A - B = A + \overline{B} + 1$. Мультиплексор 4 → 1 реалізує функцію, у якій адресні входи є змінними, а інформаційні входи несуть значення (константи або вирази від решти змінних). Докладно в [[courses/computer-architecture/lectures/05-kombinatsiini-skhemy-sumatory-deshyfratory|лекції 5]].

### Зразок розв'язання

$1011 + 0110$ (11 + 6): розряд 0: $1 + 0$, сума 1, перенесення 0; розряд 1: $1 + 1$, сума 0, перенесення 1; розряд 2: $0 + 1 + 1$, сума 0, перенесення 1; розряд 3: $1 + 0 + 1$, сума 0, перенесення 1. Результат $1\,0001$: чотирьох розрядів не вистачило (17 > 15).

## Завдання

1. Додайте 0101 + 0111 на чотирирозрядному суматорі, складіть таблицю по розрядах і вкажіть, чи є переповнення для знакових чисел.
2. Виконайте $6 - 3$ у чотирьох розрядах на суматорі-віднімачі. Запишіть $\overline{B}$, $C_0$ та результат.
3. Оцініть затримку 8-розрядного суматора з послідовним перенесенням, якщо через один розряд перенесення проходить за 0,5 нс. У скільки разів вона більша за затримку одного розряду?
4. Збудуйте дешифратор 3 → 8 із двох дешифраторів 2 → 4 із входами дозволу. Яка змінна керує дозволом?
5. Реалізуйте $F = \sum m(2, 3, 5, 7)$ на дешифраторі 3 → 8 та елементі OR. Мінімізуйте й порівняйте кількість елементів.
6. Реалізуйте функцію більшості $F = AB + AC + BC$ на мультиплексорі 4 → 1 (адреса A, B).
7. Складіть таблицю пріоритетного шифратора 4 → 2 з виходом V та виведіть формули виходів картами Карно.
8. Перетворіть у код Грея числа 1011 та 0111.

### Відповіді для самоперевірки

| Завдання | Відповідь |
|---|---|
| 1 | $0101 + 0111 = 1100$, перенесення в старший розряд 1, з нього 0: є переповнення |
| 2 | $\overline{B} = 1100$, $C_0 = 1$, результат $0011$ |
| 3 | 4 нс, у 8 разів |
| 5 | $F = \overline{A}B + AC$ (два терми замість 12 літералів ДДНФ) |
| 6 | $I_0 = 0$, $I_1 = C$, $I_2 = C$, $I_3 = 1$ |
| 8 | 1011 → 1110; 0111 → 0100 |

## Контрольні запитання

1. Чому затримка суматора з послідовним перенесенням пропорційна кількості розрядів?
2. Що таке генерація й поширення перенесення?
3. Навіщо дешифратору вхід дозволу?
4. Як на мультиплексорі $2^{n-1} \to 1$ реалізувати функцію n змінних?
