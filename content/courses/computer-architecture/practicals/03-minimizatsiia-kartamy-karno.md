# Мінімізація картами Карно

> [!abstract] Пов'язана лекція
> [[courses/computer-architecture/lectures/04-minimizatsiia-lohichnykh-funktsii-karty-karno|Лекція 4. Мінімізація логічних функцій (карти Карно, методи Куайна–МакКласкі)]]. Практична робота присвячена мінімізації логічних функцій чотирьох змінних картами Карно з урахуванням замкненості країв, невизначених станів і перевірки на небезпечні стани.

## Мета

Навчитися заповнювати карту Карно, утворювати групи максимального розміру, записувати мінімальну ДНФ, використовувати невизначені стани й помічати сусідні групи, що не перекриваються.

Після заняття ви повинні вміти:

- заповнювати карту за номерами мінтермів;
- утворювати групи по 2, 4, 8 клітинок, зокрема через край карти;
- виписувати терм із групи та мінімальну ДНФ;
- використовувати невизначені стани для збільшення груп;
- додавати надлишковий терм для усунення гонки.

## Обладнання та програмне забезпечення

- аркуш із заготовками карт (4×4) або шаблон, який ви накреслите самі;
- Python 3 або [CircuitVerse](https://circuitverse.org/) для перевірки еквівалентності вашого результату та вихідної функції.

## Теоретична частина

Дивіться [[courses/computer-architecture/lectures/04-minimizatsiia-lohichnykh-funktsii-karty-karno|лекцію 4]]. Нагадаємо правила: групи прямокутні, їхній розмір є степенем двійки, краї карти замкнені, групи можуть перетинатися, а група з $2^k$ клітинок скорочує терм на k літералів.

### Зразок розв'язання

Для $F = \sum m(0, 1, 2, 5, 6, 7, 8, 9, 10, 14)$ мінімальна форма: $F = \overline{B}\,\overline{C} + C\overline{D} + \overline{A}BD$. Групи: квадрат клітинок 0, 1, 8, 9 (через край), правий стовпчик 2, 6, 10, 14 та пара 5, 7.

## Завдання

1. Мінімізуйте $F = \sum m(1, 3, 5, 7)$ трьох змінних. Скільки літералів у ДДНФ і скільки в мінімальній формі?
2. Мінімізуйте $F = \sum m(0, 2, 5, 7, 8, 10, 13, 15)$ чотирьох змінних.
3. Мінімізуйте $F = \sum m(0, 1, 2, 5, 6, 7)$ трьох змінних. Знайдіть **два різні** мінімальні покриття.
4. Схема отримує цифру в двійково-десятковому коді (A старший розряд). Комбінації 1010–1111 не використовуються. Знайдіть мінімальні форми: а) «цифра не менша за 5»; б) «цифра парна».
5. Для $F = A\overline{B} + \overline{A}C$ знайдіть шов між групами, за якого можлива гонка при $B = 0$, $C = 1$ і зміні A. Додайте надлишковий терм.
6. Накресліть схему в базисі AND-OR-NOT для результату завдання 2 й оцініть кількість елементів.
7. Перевірте результати завдань 1, 2, 4 програмою: перебором усіх комбінацій порівняйте початкову й мінімізовану функції.

### Відповіді для самоперевірки

| Завдання | Відповідь |
|---|---|
| 1 | $F = C$ (12 літералів у ДДНФ, 1 у мінімальній) |
| 2 | $F = \overline{B}\,\overline{D} + BD$ |
| 3 | $\overline{A}\,\overline{B} + B\overline{C} + AC$ або $\overline{A}\,\overline{C} + \overline{B}C + AB$ |
| 4а | $F = A + BD + BC$ |
| 4б | $F = \overline{D}$ |
| 5 | надлишковий терм $\overline{B}\,C$: $F = A\overline{B} + \overline{A}C + \overline{B}C$ |

## Контрольні запитання

1. Чому клітинки карти нумерують за кодом Грея?
2. Чому краї карти вважаються замкненими?
3. Як використовують невизначені стани?
4. Коли доцільно додавати надлишковий терм?

## Звіт

До звіту додайте заповнені карти з обведеними групами (фото або скан), записи термів і перевірку програмою.
