# Arduino Uno у симуляторі Wokwi: цифрові входи, виходи та зсувний регістр

> [!abstract] Пов'язана лекція
> [[courses/computer-architecture/lectures/31-arduino-uno-arkhitektura-prohramuvannia-ta|Лекція 31. Arduino Uno, архітектура, програмування та застосування]], [[courses/computer-architecture/lectures/06-poslidovnisni-skhemy-tryhery-rehistry|Лекція 6. Послідовнісні схеми, тригери, регістри, лічильники]]. Лабораторна робота виконується в онлайновому симуляторі Wokwi: фізичної плати не потрібно. Ви програмуєте Arduino Uno, зчитуєте кнопку, керуєте світлодіодами напряму й через зсувний регістр 74HC595, який ми розглядали в лекції про регістри.

## Мета

Навчитися програмувати мікроконтролер, працювати з цифровими входами й виходами, використовувати зсувний регістр для розширення кількості виходів і розуміти зв'язок програмного опису з апаратною схемою.

Після заняття ви повинні вміти:

- налаштувати виводи як вхід або вихід і керувати ними;
- зчитувати кнопку з внутрішнім підтягуючим резистором;
- керувати вісьмома світлодіодами через 74HC595 трьома виводами;
- виводити діагностику через послідовний монітор.

## Обладнання та програмне забезпечення

- браузер, сайт [wokwi.com](https://wokwi.com/) (безкоштовний режим достатній; реєстрація потрібна лише для збереження проєкту);
- проєкт «Arduino Uno».

## Теоретична частина

Дивіться [[courses/computer-architecture/lectures/31-arduino-uno-arkhitektura-prohramuvannia-ta|лекцію 31]] (архітектура плати, цифрові виводи) і [[courses/computer-architecture/lectures/06-poslidovnisni-skhemy-tryhery-rehistry|лекцію 6]] (зсувний регістр). Скетч Arduino містить функцію `setup()`, що виконується один раз, і `loop()`, що повторюється. Виводи налаштовують функцією `pinMode`, читають `digitalRead`, змінюють `digitalWrite`.

## Хід роботи

### Частина 1. Світлодіод і кнопка

1. У Wokwi створіть проєкт Arduino Uno, додайте світлодіод (з резистором 220 Ом) на вивід 13 і кнопку на вивід 2 (другий контакт кнопки на GND).
2. Введіть скетч:

```cpp
const int LED = 13;
const int BTN = 2;

void setup() {
  pinMode(LED, OUTPUT);
  pinMode(BTN, INPUT_PULLUP);
  Serial.begin(9600);
}

void loop() {
  bool pressed = (digitalRead(BTN) == LOW);
  digitalWrite(LED, pressed ? HIGH : LOW);
  Serial.println(pressed ? "pressed" : "released");
  delay(100);
}
```

3. Запустіть, натискайте кнопку й спостерігайте світлодіод та вивід у моніторі. Поясніть, чому натиснута кнопка читається як LOW.

### Частина 2. Зсувний регістр 74HC595

4. Додайте 74HC595 і вісім світлодіодів із резисторами. З'єднайте: вивід 14 (DS) із виводом Arduino 11; вивід 12 (ST_CP, засувка) з виводом 10; вивід 11 (SH_CP, такт зсуву) з виводом 13 (змініть світлодіод частини 1 на інший вивід, наприклад 7); виводи 8 (GND) і 13 (OE) на землю; виводи 16 (VCC) і 10 (MR) на 5 В; виходи Q0-Q7 (виводи 15, 1-7) до світлодіодів.
5. Введіть скетч і запустіть:

```cpp
const int DATA = 11;
const int CLOCK = 13;
const int LATCH = 10;

void show(byte value) {
  digitalWrite(LATCH, LOW);
  shiftOut(DATA, CLOCK, MSBFIRST, value);
  digitalWrite(LATCH, HIGH);
}

void setup() {
  pinMode(DATA, OUTPUT);
  pinMode(CLOCK, OUTPUT);
  pinMode(LATCH, OUTPUT);
}

void loop() {
  for (int i = 0; i < 256; i++) {
    show(i);
    delay(100);
  }
}
```

6. Переконайтеся, що вісім світлодіодів показують двійкове число від 0 до 255. Поясніть, яку роль відіграє сигнал LATCH і чому без нього світлодіоди мерехтіли б під час зсуву.

### Частина 3. Бігучі вогні

7. Змініть програму так, щоб одна світна точка бігала туди й назад (значення 1, 2, 4, ... 128, потім назад).
8. (Додатково) Реалізуйте «лічильник натисків»: кожне натискання кнопки збільшує показання регістра на одиницю.

## Контрольні запитання

1. Чому кнопку підключають до землі з режимом `INPUT_PULLUP`?
2. Яку роль виконує зсувний регістр у цій схемі?
3. Навіщо засувка (LATCH) окремо від такту зсуву?
4. Скільки виводів Arduino потрібно, щоб керувати 16 світлодіодами двома регістрами?
