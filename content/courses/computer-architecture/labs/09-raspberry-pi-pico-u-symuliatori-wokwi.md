# Raspberry Pi Pico у симуляторі Wokwi: GPIO та ШІМ мовою MicroPython

> [!abstract] Пов'язана лекція
> [[courses/computer-architecture/lectures/32-raspberry-pi-arkhitektura-operatsiini-systemy|Лекція 32. Raspberry Pi, архітектура, операційні системи та застосування]]. Лабораторна робота розширює тему одноплатних комп'ютерів і мікроконтролерів: ви програмуєте Raspberry Pi Pico мовою MicroPython у симуляторі, зчитуєте кнопку, керуєте яскравістю світлодіода широтно-імпульсною модуляцією (ШІМ) та вимірюєте аналоговий сигнал.

## Мета

Навчитися керувати виводами загального призначення (GPIO) у MicroPython, застосовувати ШІМ та читати аналогове значення, порівнювати програмування Pico й Arduino.

Після заняття ви повинні вміти:

- налаштовувати GPIO як вхід і вихід;
- змінювати яскравість світлодіода ШІМ;
- читати значення потенціометра через АЦП;
- пояснювати, чим мікроконтролер Pico відрізняється від комп'ютера Raspberry Pi із повною операційною системою.

## Теоретична частина

Дивіться [[courses/computer-architecture/lectures/32-raspberry-pi-arkhitektura-operatsiini-systemy|лекцію 32]]. Raspberry Pi Pico містить мікроконтролер RP2040 і не запускає повноцінну операційну систему: програма виконується безпосередньо інтерпретатором MicroPython. ШІМ регулює середню потужність, змінюючи скважність імпульсів: чим більша частка періоду, коли вихід увімкнено, тим яскравіший світлодіод.

## Хід роботи

### Частина 1. Світлодіод і кнопка

1. У Wokwi створіть проєкт Raspberry Pi Pico (MicroPython). Додайте світлодіод із резистором на GP15 та кнопку на GP14 (другий контакт на землю).
2. Введіть програму:

```python
from machine import Pin
import time

led = Pin(15, Pin.OUT)
btn = Pin(14, Pin.IN, Pin.PULL_UP)

while True:
    led.value(0 if btn.value() else 1)
    time.sleep(0.05)
```

3. Запустіть. Світлодіод світиться, поки кнопка натиснута. Поясніть логіку інверсії.

### Частина 2. ШІМ

4. Додайте світлодіод на GP16 і програму плавного згасання й розгоряння:

```python
from machine import Pin, PWM
import time

pwm = PWM(Pin(16))
pwm.freq(1000)

while True:
    for duty in range(0, 65535, 1024):
        pwm.duty_u16(duty)
        time.sleep(0.02)
    for duty in range(65535, 0, -1024):
        pwm.duty_u16(duty)
        time.sleep(0.02)
```

5. Спостерігайте плавну зміну яскравості. Поясніть, чому частота ШІМ 1 кГц не помітна оку.

### Частина 3. АЦП

6. Додайте потенціометр, середній виводи якого підключіть до GP26 (АЦП0), крайні до 3,3 В та землі. Змініть програму так, щоб яскравість світлодіода залежала від положення потенціометра:

```python
from machine import Pin, PWM, ADC
import time

pwm = PWM(Pin(16))
pwm.freq(1000)
pot = ADC(26)

while True:
    value = pot.read_u16()
    pwm.duty_u16(value)
    print(value)
    time.sleep(0.05)
```

7. Крутіть потенціометр і занотуйте виведені значення для крайніх положень (очікується діапазон приблизно від 0 до 65535).
8. (Додатково) Порівняйте цей код з Arduino-скетчем із попередньої лабораторної: що спільного (цикл, режими виводів) і що відрізняється (мова, розрядність АЦП).
