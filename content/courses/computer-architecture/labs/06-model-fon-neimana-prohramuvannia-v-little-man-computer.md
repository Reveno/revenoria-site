# Модель фон Неймана: програмування в Little Man Computer

> [!abstract] Пов'язана лекція
> [[courses/computer-architecture/lectures/08-arkhitektura-kompiutera-model-fon-neimana-ta|Лекція 8. Архітектура комп'ютера, модель фон Неймана та Гарвардська модель]], [[courses/computer-architecture/lectures/09-tsentralnyi-protsesor-ta-aryfmetyko-lohichnyi|Лекція 9. Центральний процесор та арифметико‑логічний пристрій (АЛП)]]. Лабораторна робота показує на навчальній моделі процесора, що таке цикл вибірки й виконання команди. Ви пишете програми мовою асемблера простого комп'ютера з 100 комірками пам'яті й спостерігаєте, як змінюються регістри на кожному кроці.

## Мета

Навчитися читати й писати програми для простої моделі фон Неймана, розуміти цикл «вибірка, декодування, виконання» та значення лічильника команд, акумулятора й пам'яті.

Після заняття ви повинні вміти:

- пояснювати, що команди й дані зберігаються в одній пам'яті;
- відстежувати лічильник команд і акумулятор по кроках;
- писати програми з лінійним виконанням, циклом і умовним переходом;
- пояснювати відмінність між командою й даним у пам'яті.

## Обладнання та програмне забезпечення

- браузер і онлайновий симулятор Little Man Computer (LMC), наприклад на сайті автора Пітера Хіггінсона (peterhigginson.co.uk/lmc); подібні безкоштовні симулятори є й у вигляді застосунків;
- аркуш для запису трасування.

## Теоретична частина

Дивіться [[courses/computer-architecture/lectures/08-arkhitektura-kompiutera-model-fon-neimana-ta|лекцію 8]] та [[courses/computer-architecture/lectures/09-tsentralnyi-protsesor-ta-aryfmetyko-lohichnyi|лекцію 9]]. Модель LMC має акумулятор, лічильник команд і 100 комірок пам'яті. Основні команди: `INP` (ввести число в акумулятор), `OUT` (вивести акумулятор), `LDA x` (завантажити з комірки x), `STA x` (зберегти в комірку x), `ADD x` (додати), `SUB x` (відняти), `BRA x` (безумовний перехід), `BRZ x` (перейти, якщо акумулятор 0), `BRP x` (перейти, якщо акумулятор не від'ємний), `HLT` (зупинка), `DAT` (оголошення даних).

## Хід роботи

### Програма 1. Сума двох чисел

```
INP
STA A
INP
ADD A
OUT
HLT
A DAT
```

1. Введіть програму, запустіть, введіть 7 та 5. Очікуваний вивід: 12.
2. Увімкніть покроковий режим і заповніть таблицю: для кожної команди значення лічильника команд, акумулятора, адреси в пам'яті, до якої звертаються.

### Програма 2. Більше з двох чисел

3. Напишіть програму, що вводить два числа й виводить більше. Підказка: віднімайте й перевіряйте знак командою `BRP`.
4. Перевірте на парах (3, 8), (8, 3), (5, 5).

### Програма 3. Сума чисел від 1 до N (цикл)

```
INP
STA N
LDA ZERO
STA SUM
LOOP LDA SUM
ADD N
STA SUM
LDA N
SUB ONE
STA N
BRZ END
BRA LOOP
END LDA SUM
OUT
HLT
N DAT
SUM DAT
ZERO DAT 0
ONE DAT 1
```

5. Запустіть для N = 5. Очікуваний результат: 15. Складіть таблицю значень N та SUM на кожній ітерації.
6. Поясніть, чому для N = 0 програма працює неправильно, і виправте її.

### Дослідження

7. Змініть мітку так, щоб команда `BRA LOOP` перейшла в комірку з даними. Що відбувається? Поясніть це на прикладі того, що команда й дані в моделі фон Неймана не відрізняються в пам'яті.

## Контрольні запитання

1. Що робить лічильник команд на кожному кроці?
2. Чим відрізняється команда від даних у пам'яті моделі фон Неймана?
3. Як у програмі реалізується цикл?
4. Чим гарвардська архітектура відрізняється від архітектури фон Неймана?

## Звіт

Звіт містить тексти програм, таблиці трасування, відповіді про поведінку при N = 0 та результат дослідження п. 7.
