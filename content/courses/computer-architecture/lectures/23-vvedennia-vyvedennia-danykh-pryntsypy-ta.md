# Введення-виведення даних: принципи та інтерфейси

## Навчальні цілі заняття

- **Знати:** принципи організації введеннявиведення; класи інтерфейсів; режими обміну даними; роль контролерів та драйверів; особливості сучасних інтерфейсів.

- **Вміти:** пояснювати роботу підсистеми введеннявиведення; порівнювати інтерфейси; аналізувати режими передачі; визначати вплив швидкості інтерфейсу на продуктивність.

## 1. Вступ до введеннявиведення

Підсистема введеннявиведення забезпечує взаємодію процесора з зовнішніми пристроями. Це фундамент будівлі будьякої комп'ютерної архітектури, бо швидкість I/O часто визначає реальну продуктивність.


## 2. Режими передачі даних

Існують три основні режими.

Полінг – процесор постійно перевіряє стан пристрою;

Передача через переривання – пристрій сам повідомляє процесор про готовність;

DMA – контролер сам передає дані напряму в пам'ять, мінімізуючи навантаження на CPU. Псевдокод логіки опитування:

while true: if device.ready(): read()


## 3. Контролери введеннявиведення

Контролери координують взаємодію між CPU і периферією.

Виконують буферизацію;

Формують протоколи обміну;

Визначають швидкість роботи інтерфейсу. Приклад: у highend SSD контролер є ключовим фактором продуктивності.


## 4. Основні інтерфейси введеннявиведення

Сучасні системи використовують різні інтерфейси.

USB – універсальний послідовний інтерфейс;

SATA – для дискових накопичувачів;

PCI Express – високошвидкісна шина;

NVMe – оптимізований протокол для SSD, що працюють поверх PCIe. У мобільних пристроях USBC виконує роль універсального порту для живлення, відео та передачі даних.


## 5. Продуктивність підсистеми I/O

Пропускна здатність інтерфейсу визначає швидкість взаємодії пристроїв.

USB 3.2 перевищує можливості USB 2.0 у десятки разів;

NVMe PCIe 4.0 SSD здатні досягати 7 GB/s;

Обмеження інтерфейсу часто стає bottleneck. У геймерських системах швидкість I/O впливає на завантаження сцен у сучасних движках.

Практичні приклади

Порівняння швидкостей USB 2.0, USB 3.0 та USB 3.2.

Аналіз роботи DMA при копіюванні великих файлів.

Моделювання переривань при підключенні нового пристрою.

Оцінка пропускної здатності NVMe SSD.
