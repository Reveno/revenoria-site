# Мінімізація логічних функцій (карти Карно, методи Куайна–МакКласкі)

## Навчальні цілі заняття

- **Знати:** принципи мінімізації булевих функцій; правила групування імплікантів; особливості карт Карно для різної кількості змінних; поняття мінтермів, макстермів, простих та простих невироджених імплікантів; етапи методу Куайна–МакКласкі.

- **Вміти:** будувати карти Карно для функцій від 2–6 змінних; виконувати групування клітин; знаходити мінімальні логічні вирази; застосовувати метод Куайна–МакКласкі для формального мінімізаційного аналізу; перевіряти коректність отриманої мінімальної форми.

## 1. Поняття мінімізації логічних функцій

Мінімізація логічних функцій – це процес спрощення булевих виразів без зміни їхньої логічної поведінки. Мета – зменшити кількість логічних елементів або входів у схемі, що призводить до меншої затримки сигналу та нижчого енергоспоживання.

Мінтерми та макстерми Мінтерм – добуток усіх змінних або їх заперечень, що дорівнює 1 для однієї комбінації. Макстерм – сума змінних або їх заперечень, що дорівнює 0 для однієї комбінації.


## 2. Карти Карно: принцип побудови

Карта Карно – графічна форма подання логічної функції. Кожна клітинка відповідає одній комбінації змінних. Комбінації розташовуються у коді Грея, щоб сусідні клітини відрізнялися лише однією змінною.

Групування клітин Правила:

групуються лише клітини з 1;

розмір групи – 1, 2, 4, 8…;

чим більша група – тим простіший вираз;

дозволяється обгортання карти по краях.

Приклади мінімізації Функція F(A,B,C) = Σ(1,3,5,7). У карті Карно всі одиничні клітинки утворюють одну групу 4 → результат: F = B.


## 3. Метод Куайна–МакКласкі

Це формальний табличний метод мінімізації, що складається з:

групування мінтермів за кількістю одиниць;

пошуку простих імплікантів шляхом порівняння сусідніх груп;

формування таблиці покриття;

вибору мінімального набору імплікантів.

Метод універсальний, застосовується для автоматизованого синтезу схем.

Порівняння підходів Карти Карно – швидкий і наочний ручний метод. Куайн–МакКласкі – строгий алгоритм, придатний для великих функцій та комп'ютерної реалізації.
