# Архітектури RISC та CISC: порівняння та застосування

## Навчальні цілі заняття

- **Знати:** відмінності між архітектурами RISC та CISC; принципи побудови наборів інструкцій; вплив архітектури на продуктивність та енергоефективність; особливості конвеєрної обробки в різних архітектурах; сфери застосування RISC та CISC.

- **Вміти:** аналізувати ефективність виконання програм на різних архітектурах; будувати схеми виконання інструкцій; оцінювати переваги та обмеження RISC та CISC; проектувати прості конвеєрні схеми для різних типів процесорів.

## План лекції

1. Вступ до архітектур RISC та CISC
2. Структура та принципи роботи RISC-процесора
3. Структура та принципи роботи CISC-процесора

5. Приклади застосування RISC та CISC у сучасних системах

## Основні поняття та терміни

- RISC (Reduced Instruction Set Computer)
- CISC (Complex Instruction Set Computer)
- Набір інструкцій
- Конвеєрна обробка
- Продуктивність процесора
- Енергоефективність
- Аппаратна складність


## 1. Вступ до архітектур RISC та CISC

Архітектури процесорів визначають спосіб організації набору інструкцій і виконання обчислень. Основні підходи:

RISC – спрощений набір інструкцій, оптимізований для швидкого виконання та легкого конвеєрного розподілу;

CISC – комплексний набір інструкцій, що дозволяє виконувати складні операції однією командою.


## 2. Структура та принципи роботи RISC-процесора

Особливості RISC:

Прості інструкції, що виконуються за один такт процесора;

Велика кількість регістрів для мінімізації звернень до пам'яті;

Оптимізація під конвеєрну обробку інструкцій;

Перевага у швидкості та передбачуваності виконання програм.


## 3. Структура та принципи роботи CISC-процесора

Особливості CISC:

Багатофункціональні та складні інструкції, що можуть виконувати декілька операцій;

Менше регістрів, більша залежність від пам'яті;

Підвищена апаратна складність для декодування інструкцій;

Перевага у компактності програмного коду.


## 4. Порівняння архітектур

| Характеристика | RISC | CISC | |----------------|------|------| | Кількість інструкцій | Менше, прості | Більше, складні | | Час виконання інструкцій | Один такт (переважно) | Може займати декілька тактів | | Конвеєризація | Легко | Складно | | Аппаратна складність | Менша | Вища | | Енергоефективність | Вища | Нижча | | Застосування | Вбудовані системи, мобільні процесори | Персональні комп'ютери, сервери |

Приклади застосування RISC та CISC

RISC: ARM-процесори в смартфонах та планшетах, RISC-V у вбудованих системах;

CISC: x86-процесори в настільних ПК, ноутбуках та серверах;

Сучасні процесори часто комбінують елементи обох архітектур для підвищення продуктивності та сумісності.

Практичні приклади

Аналіз виконання простої програми на RISC та CISC, оцінка часу виконання.

Моделювання конвеєрної обробки інструкцій у RISC-процесорі.

Виявлення обмежень при використанні складних інструкцій у CISC.

Проектування простих схем виконання арифметичних та логічних операцій для обох архітектур.
