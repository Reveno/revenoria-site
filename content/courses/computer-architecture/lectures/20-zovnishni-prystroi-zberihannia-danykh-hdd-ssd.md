# Зовнішні пристрої зберігання даних (HDD, SSD, оптичні диски)

## Навчальні цілі заняття

- **Знати:** основні типи зовнішніх пристроїв зберігання даних; принципи роботи HDD, SSD та оптичних дисків; характеристики швидкості, надійності та довговічності; вплив типу пристрою на продуктивність системи.

- **Вміти:** порівнювати різні пристрої зберігання даних; аналізувати продуктивність та надійність дискових систем; проектувати схеми зберігання даних; обирати оптимальний тип накопичувача для конкретних завдань.

## План лекції

1. Вступ до зовнішніх пристроїв зберігання даних
2. Жорсткі диски (HDD): будова та принцип роботи
3. Твердотільні накопичувачі (SSD): особливості та технології
4. Оптичні диски: типи та сфери застосування
5. Порівняння та вибір пристроїв зберігання даних

## Основні поняття та терміни

- HDD (Hard Disk Drive)
- SSD (Solid State Drive)
- Оптичні диски (CD, DVD, Blu-ray)
- Час доступу та швидкість передачі даних
- MTBF (Mean Time Between Failures)
- Надійність та довговічність
- RAID та системи резервування


## 1. Вступ до зовнішніх пристроїв зберігання даних

Зовнішні накопичувачі забезпечують довготривале зберігання інформації та розвантажують оперативну пам'ять. Вибір пристрою впливає на швидкість доступу, надійність та енергоспоживання системи.


## 2. Жорсткі диски (HDD): будова та принцип роботи

Магнітні пластини та головки читання/запису;

Обертання шпинделя та затримка доступу;

Параметри: об'єм, швидкість обертання, кеш-пам'ять;

Використання у серверах, персональних комп'ютерах та системах з великим об'ємом даних.


## 3. Твердотільні накопичувачі (SSD): особливості та технології

NAND Flash та контролери;

Відсутність механічних частин, швидкість доступу;

Обмежена кількість циклів запису/стираня;

Використання у мобільних пристроях, ноутбуках, серверах.


## 4. Оптичні диски: типи та сфери застосування

CD, DVD, Blu-ray;

Принцип роботи лазерного читання та запису;

Застосування для архівування, мультимедіа та довгострокового зберігання.


## 5. Порівняння та вибір пристроїв зберігання даних

Порівняння швидкості, надійності та вартості;

Вибір HDD для великих об'ємів зберігання;

Використання SSD для високої швидкості доступу;


## 6. Оптичні диски

для архівування та резервного копіювання.

Практичні приклади

Визначення продуктивності HDD та SSD за допомогою тестових програм.

Побудова простої RAID-конфігурації для надійності даних.

Аналіз терміну служби SSD з урахуванням циклів запису.

Вибір оптимального пристрою для конкретного завдання: архівування, ігри, бази даних.
