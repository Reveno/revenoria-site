# Ієрархія пам'яті та основні типи (RAM, ROM, Flash)

## Навчальні цілі заняття

- **Знати:** принципи організації пам'яті в комп'ютерних та вбудованих системах; особливості основних типів пам'яті RAM, ROM та Flash; вплив пам'яті на продуктивність та енергоефективність; архітектурні рішення для швидкого доступу до даних.

- **Вміти:** аналізувати ієрархію пам'яті; вибирати тип пам'яті для конкретних задач; оцінювати вплив різних типів пам'яті на продуктивність систем; проектувати прості схеми доступу до даних та оптимізації кешування.

## План лекції

1. Вступ до ієрархії пам'яті
2. Оперативна пам'ять (RAM): типи та принципи роботи
3. Постійна пам'ять (ROM) та її різновиди

## Основні поняття та терміни

- Ієрархія пам'яті
- RAM (Random Access Memory)
- DRAM, SRAM
- ROM (Read-Only Memory)
- Flash-пам'ять
- Кеш-пам'ять
- Швидкість доступу та латентність


## 1. Вступ до ієрархії пам'яті

Ієрархія пам'яті організована для балансування продуктивності та вартості системи. Основні рівні включають регістри, кеш, оперативну пам'ять, Flash та довготривалу зберігаючу пам'ять.


## 2. Оперативна пам'ять (RAM): типи та принципи роботи

DRAM: динамічна пам'ять з необхідністю періодичного оновлення;

SRAM: статична пам'ять, швидка та енергоємка;

Використання RAM для тимчасового зберігання даних та програм.


## 3. Постійна пам'ять (ROM) та її різновиди

Базова ROM: незмінна програма виробника;

PROM, EPROM, EEPROM: програмована та стираючася пам'ять;

Використання для зберігання мікропрограм та системного ПЗ.


## 4. Flash-пам'ять: особливості та застосування

NAND та NOR Flash;

Застосування у SSD, USB-накопичувачах, мобільних пристроях;

Особливості циклів запису/стираня та довговічність.


## 5. Ієрархія пам'яті та вплив на продуктивність систем

Взаємодія кешу, RAM та довготривалої пам'яті;

Зменшення латентності та затримок доступу;

Стратегії кешування та управління пам'яттю для оптимальної продуктивності.

Практичні приклади

Розрахунок часу доступу до даних при використанні різних рівнів пам'яті.

Моделювання роботи кешу для прискорення обчислень.

Аналіз продуктивності системи при зміні типу оперативної пам'яті.

Порівняння NAND і NOR Flash для різних сценаріїв використання.
