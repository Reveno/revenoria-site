# Архітектура мобільних систем (смартфони, планшети)

## Навчальні цілі заняття

- **Знати:** особливості архітектури мобільних процесорів; взаємодію компонентів у смартфонах та планшетах; принципи енергоефективності та оптимізації; організацію обчислювальних та графічних потоків; основні стандарти мобільних систем.

- **Вміти:** аналізувати структуру мобільної системи; моделювати обчислювальні потоки на мобільних пристроях; оцінювати продуктивність CPU та GPU у мобільних системах; оптимізувати розподіл ресурсів та енергії; проектувати прості схеми обробки даних у мобільних пристроях.

## План лекції

1. Вступ до архітектури мобільних систем
2. Основні компоненти смартфонів та планшетів
3. Процесори та графічні ядра у мобільних пристроях
4. Організація обчислювальних та графічних потоків
5. Енергоефективність та оптимізація роботи мобільних систем

## Основні поняття та терміни

- Мобільна система
- SoC (System on Chip)
- CPU та GPU мобільних пристроїв
- Пам'ять та кеш
- Енергоефективність
- Обчислювальні потоки
- Периферійні компоненти


## 1. Вступ до архітектури мобільних систем

Мобільні пристрої мають компактну та енергоефективну архітектуру, що забезпечує високопродуктивну обробку даних і графіки при обмеженій потужності батареї. Основні принципи: інтеграція всіх ключових компонентів на одному чипі (SoC), баланс продуктивності та енергоефективності.


## 2. Основні компоненти смартфонів та планшетів

Процесорні ядра (CPU) для загальних обчислень;

Графічні ядра (GPU) для обробки зображень та відео;

Модулі пам'яті та кешу;

Контролери вводу/виводу та сенсорні інтерфейси;

Комунікаційні модулі: Wi-Fi, LTE/5G, Bluetooth.


## 3. Процесори та графічні ядра у мобільних пристроях

CPU мобільних систем зазвичай багатоядерні (big.LITTLE) для енергоефективності;

GPU мобільних пристроїв оптимізовані для паралельної обробки графіки та обчислювальних задач;

Інтеграція CPU та GPU в SoC дозволяє зменшити затримки та енергоспоживання.


## 4. Організація обчислювальних та графічних потоків

Паралельне виконання обчислювальних задач на багатоядерних CPU та GPU;

Використання SIMD-паралелізму для обробки масивів даних;

Управління ресурсами та пріоритетами потоків для ефективної роботи системи.


## 5. Енергоефективність та оптимізація роботи мобільних систем

Використання спеціальних режимів енергозбереження;

Динамічне регулювання частоти та напруги процесорів (DVFS);

Оптимізація графічних та обчислювальних задач для мінімізації споживання енергії;

Баланс між продуктивністю та тривалістю роботи батареї.

Практичні приклади

Моделювання роботи мобільного CPU та GPU під час обробки відео.

Аналіз енергоефективності різних режимів роботи багатоядерного процесора.

Оптимізація паралельних обчислювальних потоків на мобільному SoC.

Визначення пріоритетів обробки задач для підвищення продуктивності та економії енергії.
