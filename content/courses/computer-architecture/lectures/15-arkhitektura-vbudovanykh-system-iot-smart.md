# Архітектура вбудованих систем (IoT, smart-devices)

## Навчальні цілі заняття

- **Знати:** особливості архітектури вбудованих систем; типові компоненти IoT та smart-devices; принципи енергоефективності та комунікаційних протоколів; організацію обчислювальних та сенсорних потоків; стандарти та безпеку вбудованих систем.

- **Вміти:** аналізувати структуру вбудованих систем; моделювати обчислювальні та сенсорні потоки; оцінювати продуктивність та енергоспоживання; проектувати прості схеми взаємодії компонентів IoT; оптимізувати роботу smart-devices.

## План лекції

1. Вступ до архітектури вбудованих систем
2. Основні компоненти IoT та smart-devices
3. Обчислювальні та сенсорні потоки
4. Комунікаційні протоколи та енергоефективність
5. Безпека та стандарти вбудованих систем

## Основні поняття та терміни

- Вбудована система
- IoT (Internet of Things)
- Smart-devices
- Сенсори та актуатори
- Мікроконтролери та SoC
- Комунікаційні протоколи (MQTT, CoAP)
- Енергоефективність та безпека


## 1. Вступ до архітектури вбудованих систем

Вбудовані системи – це спеціалізовані комп'ютерні системи, інтегровані у пристрої для виконання конкретних функцій. Вони забезпечують автономність, низьке енергоспоживання та інтеграцію з іншими IoT-пристроями.


## 2. Основні компоненти IoT та smart-devices

Мікроконтролери та SoC для обробки даних;

Сенсори для збору інформації про середовище;

Актуатори для фізичного впливу на об'єкти;

Модулі пам'яті та кеш;

Комунікаційні модулі: Wi-Fi, Bluetooth, ZigBee, LoRaWAN.


## 3. Обчислювальні та сенсорні потоки

Паралельна обробка сенсорних даних;

Використання DMA та апаратних прискорювачів для ефективності;

Організація пріоритетів задач та потоків для стабільної роботи системи.


## 4. Комунікаційні протоколи та енергоефективність

MQTT та CoAP для обміну даними між пристроями;

Оптимізація енергоспоживання через режими сну та пробудження;

Баланс продуктивності та тривалості автономної роботи.


## 5. Безпека та стандарти вбудованих систем

Захист даних та аутентифікація пристроїв;

Шифрування каналів комунікації;

Дотримання стандартів IoT та сумісність між пристроями.

Практичні приклади

Моделювання роботи сенсорного потоку у smart-device.

Налаштування комунікаційного протоколу MQTT між двома IoT-пристроями.

Аналіз енергоспоживання мікроконтролера у різних режимах.

Розробка простого сценарію безпечної передачі даних між IoT-пристроями.
