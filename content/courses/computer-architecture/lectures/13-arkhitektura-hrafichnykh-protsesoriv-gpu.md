## 1. Вступ до архітектури GPU

Графічний процесор (GPU) – спеціалізований процесор для швидкої обробки графічних та паралельних обчислень. GPU має сотні чи тисячі ядер, що дозволяє виконувати одночасно велику кількість обчислень.


## 2. Основні відмінності GPU та CPU

CPU: оптимізований для послідовних задач, невелика кількість потужних ядер;

GPU: оптимізований для паралельних задач, велика кількість простих ядер;

GPU обробляє великі масиви даних одночасно, CPU виконує складну логіку та керує системою.


## 3. Паралельна обробка та обчислювальні потоки

Шейдери та ядра GPU працюють у паралельних потоках;

SIMD-паралелізм для одночасного застосування однієї операції до багатьох елементів;

Організація обчислювальних потоків та керування ресурсами для оптимальної продуктивності.


## 4. Моделі обробки графіки у GPU

Растеризація – перетворення геометрії сцени у пікселі;

Текстурування та освітлення – додаткові етапи обробки зображення;

Обчислювальні шейдери (Compute Shaders) для універсальних паралельних обчислень.


## 5. Застосування GPU у сучасних системах

Ігрові та мультимедійні додатки;

Наукові обчислення та симуляції;

Штучний інтелект та машинне навчання;

Криптографія та обробка великих даних.

Практичні приклади

Моделювання роботи GPU для обчислення великого масиву даних.

Створення простого шейдера для обробки зображення.

Аналіз продуктивності різних конфігурацій ядер GPU.

Оптимізація обчислювальних потоків для паралельних задач.
