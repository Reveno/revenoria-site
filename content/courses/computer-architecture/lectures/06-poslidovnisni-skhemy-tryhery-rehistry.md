# Послідовнісні схеми: тригери, регістри, лічильники

## Навчальні цілі заняття

- **Знати:** принцип роботи послідовних схем; типи тригерів (RS, JK, D, T) та їх таблиці переходів; будову і призначення регістрів та лічильників; способи синхронізації; застосування послідовних схем у цифрових пристроях.

- **Вміти:** аналізувати роботу тригерів, регістрів і лічильників; будувати таблиці станів; визначати функціональне призначення компонентів; проектувати прості послідовні схеми для різних цифрових задач.

## План лекції

1. Послідовні схеми: визначення та принцип роботи
2. Тригери: класифікація, таблиці переходів
3. Регістри: типи та використання
4. Лічильники: конструкції та принцип роботи
5. Синхронізація та застосування послідовних схем

## Основні поняття та терміни

- Послідовна схема

- Синхронізація
- Асинхронна та синхронна логіка


## 1. Послідовні схеми: визначення та принцип роботи

Послідовні схеми – це цифрові пристрої, вихід яких залежить не тільки від поточних значень входів, але й від попереднього стану. На відміну від комбінаційних схем, вони містять елементи пам'яті. Основні сфери застосування послідовних схем включають обчислювальні пристрої, регістри зберігання даних, лічильники, системи керування.


## 2. Тригери

Тригер – це базовий елемент пам'яті, який може перебувати у двох стабільних станах. Основні типи тригерів:

2.1. RS-тригер Має два входи: Set (S) та Reset (R). Таблиця переходів:

S=0, R=0 → стан зберігається;

S=1, R=0 → встановлення в 1;

S=0, R=1 → встановлення в 0;

S=1, R=1 → заборонене стан. Використовується для базових схем зберігання бітів.

2.2. JK-тригер Схожий на RS-тригер, але заборонений стан відсутній. Має властивість переключення при J=K=1. Таблиця переходів:

J=0, K=0 → стан зберігається;

J=0, K=1 → встановлення в 0;

J=1, K=0 → встановлення в 1;

J=1, K=1 → переключення стану.

2.3. D-тригер Вхід D подає дані на вихід при наявності тактового сигналу. Забезпечує просте і синхронне зберігання бітів.

2.4. T-тригер Виконує функцію перемикання стану при кожному імпульсі тактового сигналу. Часто використовується в лічильниках.


## 3. Регістри

Регістр – група тригерів, що зберігає багатобітову інформацію.

3.1. Типи регістрів

Зсувні регістри (Shift Registers): дані пересуваються по тригерах за тактовим сигналом;

Паралельні регістри: всі біти записуються одночасно;

Кільцеві регістри: послідовність даних циркулює по колу.


### Використання регістрів

Регістри застосовують для тимчасового зберігання інформації, буферизації даних, перетворення послідовності сигналів.


## 4. Лічильники

Лічильник – послідовна схема для підрахунку імпульсів.

4.1. Класифікація

Асинхронні лічильники (Ripple Counters): кожний тригер керує наступним;

Синхронні лічильники: всі тригери отримують однаковий тактовий сигнал;

Декодові лічильники: генерують коди по заданій послідовності.


### Принцип роботи

Лічильники реалізують арифметичні функції додавання/віднімання та формують часові інтервали.


## 5. Синхронізація та застосування послідовних схем

Синхронізація забезпечується використанням єдиного тактового сигналу, що координує зміну станів усіх тригерів та регістрів. Застосування:

Генерація послідовностей імпульсів;

Зберігання та пересилка даних у цифрових системах;

Управління процесами в мікропроцесорах та FPGA.

Практичні приклади

Побудова RS-тригера на логічних елементах NAND/OR. Вхідні сигнали задаються вручну, вихід контролюється лампами або світлодіодами.

Розробка 4-бітного зсувного регістру для пересилки байту даних.

Створення 3-бітного синхронного лічильника для підрахунку імпульсів від генератора.

Проектування JK-тригера з функцією перемикання стану для керування LED-світлодіодом.
