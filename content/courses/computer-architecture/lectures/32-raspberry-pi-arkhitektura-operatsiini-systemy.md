# Raspberry Pi: архітектура, операційні системи та застосування

## Основні поняття та терміни

- Одноплатний комп'ютер – комп'ютер, реалізований на одній друкованій платі з усіма основними компонентами;
- Процесор ARM – енергоефективний 64-бітовий процесор, що є ядром платформи Raspberry Pi;
- Операційна система Linux – програмне середовище для управління ресурсами Raspberry Pi та виконання програм;
- GPIO – універсальні цифрові порти для підключення датчиків та виконавчих пристроїв;
- Шина I2C та SPI – стандарти обміну даними з периферійними пристроями;
- Програмна оболонка Python – основна мова програмування для Raspberry Pi, з підтримкою численних бібліотек.

- Архітектура Raspberry Pi Raspberry Pi побудована на базі процесора ARM Cortex-A, який забезпечує високу продуктивність при низькому енергоспоживанні. Платформа оснащена оперативною пам'яттю типу LPDDR, USB-портами для підключення периферії, HDMI-виходом для монітора, мережевим інтерфейсом Ethernet і Wi-Fi, а також GPIO для роботи з сенсорами і виконавчими механізмами. Основні компоненти:
- Процесор – обробляє інструкції та керує роботою всіх підсистем
- Оперативна пам'ять – забезпечує швидкий доступ до даних і програм
- Постійна пам'ять (SD-карта) – містить операційну систему та користувацькі файли
- GPIO та периферійні інтерфейси – для взаємодії з датчиками, моторчиками та іншими пристроями
- Периферійні порти USB, HDMI, аудіо – для підключення зовнішніх пристроїв

- Операційні системи на Raspberry Pi Raspberry Pi підтримує різні дистрибутиви Linux, зокрема Raspberry Pi OS (раніше Raspbian), Ubuntu, а також спеціалізовані ОС для медіацентрів або робототехніки. Основні аспекти роботи з ОС:
- Завантаження та налаштування системи з SD-карти
- Використання командного рядка для управління системою
- Інсталяція пакетів та бібліотек через apt або pip
- Робота з мережевими протоколами та інтернетом

Програмування Raspberry Pi Raspberry Pi зазвичай програмується мовою Python, яка дозволяє швидко створювати скрипти для керування GPIO, взаємодії з сенсорами, обробки даних та запуску серверних застосунків. Інші мови, такі як C/C++, Java або Node.js, також підтримуються, що робить платформу універсальною для різних проектів.

- Застосування Raspberry Pi Raspberry Pi використовується у різних сферах:
- Освітні проекти – навчання програмуванню та робототехніці
- Домашня автоматизація – управління освітленням, кліматом, системами безпеки
- IoT та smart-devices – збір, обробка та передача даних з сенсорів
- Медіацентри та медіа-плеєри
- Прототипування комерційних рішень

Практичні приклади

- Контроль світлодіода через GPIO
- Підключення світлодіода до GPIO
- Використання бібліотеки RPi.GPIO для управління станом виходу
- Реалізація циклічного миготіння

- Зчитування температури та вологості з датчика DHT11
- Підключення датчика до GPIO
- Використання бібліотеки Adafruit_DHT для отримання даних
- Виведення результатів на консоль або веб-інтерфейс

- Домашній медіацентр
- Встановлення дистрибутива LibreELEC або Kodi
- Підключення до монітора через HDMI
- Відтворення мультимедійного контенту та управління через пульт або мережу
