# Інструменти та фреймворки для роботи з нейронними мережами

> [!abstract] Коротко
> Оглядова лекція про інструментарій. Порівнюємо TensorFlow з [[courses/neural-networks/glossary/keras|Keras]] і PyTorch, розбираємося, чому навчання мереж вимагає GPU чи TPU замість звичайного процесора, і які хмарні платформи дозволяють працювати з мережами без власного дорогого обладнання.

## Навчальні цілі заняття

- Знати: про існування спеціалізованих бібліотек для глибокого навчання, ключових гравців на ринку (TensorFlow, PyTorch, Keras) та їхні основні характеристики.

- Вміти: розуміти роль GPU в прискоренні навчання та знати про існування хмарних платформ, таких як Google Colab, для доступу до обчислювальних ресурсів.

## 1. Екосистема глибокого навчання

Створення та навчання нейронних мереж з нуля, як ми робили це концептуально на попередніх лекціях, — надзвичайно складний процес. Він вимагає реалізації матричних операцій, автоматичного диференціювання для алгоритму зворотного поширення помилки, оптимізаторів та багато іншого.

На щастя, нам не потрібно робити це вручну. Існує розвинена екосистема фреймворків для глибокого навчання (Deep Learning Frameworks) — це бібліотеки, які надають усі необхідні інструменти для швидкого створення, навчання та розгортання нейронних мереж.

Ці фреймворки дозволяють нам працювати на високому рівні абстракції. Замість того, щоб описувати математику кожного шару, ми можемо просто сказати: "Створи мені [[courses/neural-networks/glossary/zhortkovyi-shar|згортковий шар]] з 32 фільтрами розміром 3x3 та функцією активації [[courses/neural-networks/glossary/relu|ReLU]]". Фреймворк сам подбає про всі низькорівневі деталі.

## 2. Ключові фреймворки

Сьогодні на ринку домінують два основні фреймворки.

TensorFlow та Keras

- TensorFlow:

  - Розробник: Google Brain.

  - Особливості: Це потужна низькорівнева бібліотека. Її основна ідея — представлення всіх обчислень у вигляді статичного обчислювального графа. Ви спочатку визначаєте всю структуру обчислень, а потім "запускаєте" дані через цей граф. Це дозволяє проводити значні оптимізації перед виконанням. TensorFlow є дуже гнучким, масштабованим і чудово підходить для розгортання моделей у промислових середовищах (production).

- Keras:

  - Розробник: Франсуа Шолле (співробітник Google).

  - Особливості: Keras — це високорівневе API, яке створене для максимальної простоти та швидкості розробки. Воно працює "поверх" TensorFlow (а раніше могло працювати й поверх інших бібліотек). Keras дозволяє будувати складні моделі за допомогою дуже простого та інтуїтивно зрозумілого синтаксису, що робить його ідеальним вибором для початківців та для швидкого прототипування. Сьогодні Keras є офіційним високорівневим API для TensorFlow.

Приклад коду на Keras для створення простої мережі:

import tensorflow as tf

from tensorflow import keras

model = keras.Sequential(\[

keras.layers.Flatten(input_shape=(28, 28)), \# Вхідний шар

keras.layers.Dense(128, activation='relu'), \# [[courses/neural-networks/glossary/prykhovanyi-shar|Прихований шар]]

keras.layers.Dense(10, activation='[[courses/neural-networks/glossary/softmax|softmax]]') \# Вихідний шар

\])

model.compile(optimizer='adam',

loss='sparse_categorical_crossentropy',

metrics=\['accuracy'\])

PyTorch

- Розробник: Facebook AI Research (FAIR).

- Особливості: Головний конкурент TensorFlow. Його ключова відмінність — динамічні обчислювальні графи. Граф будується "на льоту" під час виконання коду. Це робить процес налагодження (debugging) значно простішим і дає більшу гнучкість, особливо для складних архітектур (як-от в RNN). PyTorch має дуже "пітонівський" (pythonic) синтаксис і є надзвичайно популярним у дослідницькому середовищі.

Вибір між TensorFlow/Keras та PyTorch — це часто питання особистих вподобань та специфіки задачі. Обидва фреймворки є потужними, мають величезну спільноту та чудову документацію. Для початківців найпростішим шляхом є Keras.

## 3. Роль апаратного забезпечення: CPU vs. GPU vs. TPU

Навчання глибоких нейронних мереж — це, по суті, виконання величезної кількості матричних множень та додавань.

- CPU (Central Processing Unit — Центральний процесор): Це "мозок" комп'ютера. Він має кілька дуже потужних ядер, оптимізованих для послідовного виконання складних завдань. Для матричних операцій він не дуже ефективний. Навчання навіть простої моделі на CPU може зайняти години або дні.

- GPU (Graphics Processing Unit — Графічний процесор): Спочатку розроблені для рендерингу графіки в іграх, GPU мають тисячі менш потужних, але спеціалізованих ядер, які ідеально підходять для паралельного виконання простих математичних операцій. Саме такою операцією є матричне множення. Використання GPU може прискорити навчання нейронних мереж в 10-100 разів порівняно з CPU.

- TPU (Tensor Processing Unit — Тензорний процесор): Це спеціалізовані мікросхеми (ASIC), розроблені Google спеціально для прискорення обчислень з тензорами (багатовимірними масивами), які є основою TensorFlow. TPU пропонують ще вищу продуктивність для певних типів моделей.

Висновок: для серйозної роботи з глибоким навчанням наявність потужного GPU є практично обов'язковою.

## 4. Хмарні платформи для глибокого навчання

Що робити, якщо у вас немає потужного комп'ютера з дорогим GPU? Використовувати хмарні сервіси.

- Google Colaboratory (Colab): Це безкоштовний сервіс від Google, який надає середовище Jupyter Notebook, що виконується у хмарі. Найголовніше — Colab надає безкоштовний доступ до GPU (а іноді й TPU). Це ідеальний інструмент для навчання, експериментів та виконання завдань, які не вимагають тижнів безперервних обчислень.

- Професійні хмарні платформи: Для великих проектів використовуються платні сервіси, такі як:

  - Amazon Web Services (AWS) SageMaker

  - Google Cloud AI Platform

  - Microsoft Azure Machine Learning Вони дозволяють орендувати будь-яку кількість потужних GPU/TPU, керувати даними, навчати та розгортати моделі в промислових масштабах.

Використання фреймворків та хмарних платформ зробило глибоке навчання доступним для широкого кола розробників та дослідників по всьому світу.
