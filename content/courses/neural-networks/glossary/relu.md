# ReLU

> [!definition] Визначення
> Функція активації, що повертає нуль для від'ємних значень і сам аргумент для додатних: f(x) = max(0, x). Сучасний стандарт для прихованих шарів — проста, швидка й не має проблеми зникаючого градієнта в додатній області.

> [!example] Приклад
> На вхід −3 ReLU дає 0, на вхід 2,5 — 2,5.
