# Розробка CNN для класифікації кольорових зображень (CIFAR-10)

## Професійні компетентності

Після виконання практичної роботи здобувач освіти повинен навчитися будувати, навчати та оцінювати згорткову нейронну мережу (CNN) для розв'язання задачі класифікації на більш складному наборі даних з кольоровими зображеннями.

В ході виконання практичної роботи здобувачі передвищої фахової освіти повинні набути наступні програмні компетентності:

- СК01. Здатність алгоритмічно та логічно мислити.

- СК07. Здатність розробляти модулі і компоненти програмного забезпечення за допомогою типових алгоритмів та інструментів.

## Перелік необхідного обладнання та програмного забезпечення

- Персональний комп'ютер з операційною системою (Windows, Linux або macOS).

## Теоретична частина

Набір даних CIFAR-10 – це один зі стандартних наборів даних для задач комп'ютерного зору. Він складається з 60 000 кольорових зображень розміром 32x32 пікселі, розділених на 10 класів. На відміну від MNIST та Fashion-MNIST, зображення в CIFAR-10 мають 3 канали кольору (RGB), що робить задачу значно складнішою і вимагає більш потужних архітектур, таких як згорткові нейронні мережі.

Класи в CIFAR-10:

airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck.

Архітектура CNN для кольорових зображень:

Принцип побудови CNN для CIFAR-10 схожий на той, що використовувався для MNIST, але з деякими особливостями:

1.  Вхідний розмір: input_shape для першого шару має враховувати розмір зображення та кількість каналів: (32, 32, 3).

2.  Глибина мережі: Через більшу складність даних, зазвичай, потрібна глибша архітектура: кілька блоків згорткових та пулінгових шарів (Conv2D + MaxPooling2D).

3.  Кількість фільтрів: Часто кількість фільтрів у згорткових шарах збільшується по мірі проходження сигналу вглиб мережі (наприклад, 32 -\> 64 -\> 128). Це дозволяє мережі вивчати все більш складні та абстрактні патерни.

[[courses/neural-networks/glossary/rehuliaryzatsiia|Регуляризація]]: Для боротьби з перенавчанням на складних даних активно використовуються шари [[courses/neural-networks/glossary/dropout|Dropout]].

## Практична частина

Завдання: Створити, навчити та оцінити згорткову нейронну мережу для класифікації зображень з набору даних CIFAR-10.

Порядок виконання:

1.  Створіть новий ноутбук Practical_6_MyName.ipynb.

2.  Завантажте та підготуйте дані:

- Імпортуйте TensorFlow та інші необхідні бібліотеки.

- Завантажте датасет cifar10.

- Нормалізуйте значення пікселів навчальних та тестових зображень, поділивши їх на 255.0.

- Створіть масив з назвами класів для візуалізації.

1.  Візуалізуйте дані. Виведіть на екран сітку з 25 випадковими зображеннями з навчальної вибірки разом з їхніми мітками, щоб ознайомитися з даними.

2.  Побудуйте архітектуру моделі CNN. Створіть Sequential модель. Ви можете експериментувати, але рекомендована базова архітектура така:

- Conv2D шар (32 фільтри, ядро 3x3, активація '[[courses/neural-networks/glossary/relu|relu]]', input_shape=(32, 32, 3))

- MaxPooling2D шар (розмір пулу 2x2)

- Conv2D шар (64 фільтри, ядро 3x3, активація 'relu')

- MaxPooling2D шар (розмір пулу 2x2)

- Conv2D шар (64 фільтри, ядро 3x3, активація 'relu')

- Шар Flatten

- Dense шар (64 нейрони, активація 'relu')

- Dense шар (10 нейронів, активація '[[courses/neural-networks/glossary/softmax|softmax]]')

- Виведіть структуру моделі за допомогою model.summary().

1.  Скомпілюйте модель. Використовуйте оптимізатор 'adam', функцію втрат 'sparse_categorical_crossentropy' та метрику \['accuracy'\].

2.  Навчіть модель. Використовуйте метод fit() для навчання протягом 10-15 епох. Обов'язково використовуйте тестові дані як валідаційні (validation_data=(x_test, y_test)) для моніторингу [[courses/neural-networks/glossary/perenavchannia|перенавчання]].

3.  Оцініть точність. Використайте метод evaluate() для визначення фінальної точності моделі на тестових даних.

4.  Проаналізуйте процес навчання. Побудуйте графіки точності та втрат для навчальної та валідаційної вибірок. Проаналізуйте їх на наявність перенавчання.

Зробіть висновок. Опишіть отриману точність. Проаналізуйте, наскільки добре модель впоралася із завданням і чи спостерігалося перенавчання.
