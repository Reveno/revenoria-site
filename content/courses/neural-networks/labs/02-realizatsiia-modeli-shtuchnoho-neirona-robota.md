## Теоретична частина

[[courses/neural-networks/glossary/shtuchnyi-neiron|Штучний нейрон]] — це математична функція, яка є спрощеною моделлю біологічного нейрона. Вона отримує один або кілька вхідних сигналів, обробляє їх і видає один вихідний сигнал.

Процес обробки складається з двох етапів:

1.  Обчислення зваженої суми (net): Кожен вхідний сигнал xᵢ множиться на відповідну йому вагу wᵢ. Потім усі ці добутки підсумовуються. Це можна розглядати як обчислення скалярного добутку вектора входів X на вектор ваг W. Часто до суми додається [[courses/neural-networks/glossary/zmishchennia|зміщення]] (bias, b), яке дозволяє нейрону бути більш гнучким та краще налаштовуватися на дані.\
    net = (x₁\*w₁ + x₂\*w₂ + ... + xₙ\*wₙ) + b = Σ(xᵢ\*wᵢ) + b

2.  Застосування функції активації (φ): Зважена сума net пропускається через нелінійну функцію активації φ(net), яка перетворює її на кінцевий вихідний сигнал нейрона out. Ця нелінійність є критично важливою, оскільки саме вона дозволяє нейронним мережам вивчати складні залежності.

out = φ(net)

Бібліотека NumPy — це фундаментальна бібліотека для наукових обчислень мовою Python. Вона надає потужні інструменти для роботи з багатовимірними масивами (векторами, матрицями) та математичними функціями. Для наших завдань ключовими є:

- np.array(): створення масивів NumPy.

- np.dot(a, b) або a @ b: обчислення скалярного добутку векторів або множення матриць.

- np.exp(x): обчислення експоненти eˣ.

## Практична частина

Крок 1: Імпорт бібліотеки та визначення функції активації

```python
# Імпортуємо бібліотеку NumPy для математичних операцій
```

3.  Напишіть функцію для сигмоїдної функції активації. Вона є однією з найпопулярніших і має вигляд φ(x) = 1 / (1 + e⁻ˣ). Ця функція "стискає" будь-яке вхідне значення у діапазон від 0 до 1.

```python
def sigmoid(x):
  # Реалізація сигмоїдної функції активації
  # f(x) = 1 / (1 + e^(-x))
  return 1 / (1 + np.exp(-x))

Крок 2: Реалізація класу Neuron
```

1.  Створіть клас Neuron мовою Python, який буде представляти наш штучний нейрон.

2.  В конструкторі \_\_init\_\_ класу визначте, що нейрон прийматиме ваги (weights) та зміщення (bias) під час створення.

3.  Створіть метод predict(inputs), який буде обчислювати вихід нейрона за формулами, наведеними у теоретичній частині.

```python
class Neuron:
    def __init__(self, weights, bias):
        # Ініціалізуємо нейрон з заданими вагами та зміщенням
        self.weights = weights
        self.bias = bias

    def predict(self, inputs):
        # Крок 1: Обчислюємо зважену суму входів
        weighted_sum = np.dot(inputs, self.weights) + self.bias
        # Крок 2: Застосовуємо функцію активації до зваженої суми
        return sigmoid(weighted_sum)
```

Крок 3: Тестування нейрона

1.  Визначте ваги та зміщення. Нехай наш нейрон має 2 входи.

```python
# Ваги для двох входів (w1=0, w2=1)
weights = np.array([0, 1])
# Зміщення (b=4)
bias = 4                  
```

2.  Створіть екземпляр (об'єкт) класу Neuron з цими параметрами:

```python
# Створюємо нейрон з нашими вагами та зміщенням
n = Neuron(weights, bias)
```

3.  Визначте вхідні дані та зробіть прогноз за допомогою створеного методу predict.

```python
# Вхідні дані (x1=2, x2=3)
inputs = np.array([2, 3])
prediction = n.predict(inputs)

print("--- Розрахунок виходу нейрона ---")
print(f"Вхідні дані (x): {inputs}")
print(f"Ваги (w): {weights}")
print(f"Зміщення (b): {bias}")
print(f"Прогноз нейрона (out): {prediction}")
```

4.  Самоперевірка: Перевірте обчислення вручну, щоб переконатися у правильності роботи коду.

- net = (x₁ \* w₁) + (x₂ \* w₂) + b = (2 \* 0) + (3 \* 1) + 4 = 7

out = 1 / (1 + e⁻⁷) ≈ 1 / (1 + 0.00091) ≈ 0.999
