## Теоретична частина

Keras – це високорівневий API (інтерфейс програмування застосунків) для створення та навчання моделей глибокого навчання, який інтегровано в бібліотеку TensorFlow. Keras дозволяє швидко та інтуїтивно будувати складні нейронні мережі.

Основна модель в Keras – Sequential. Вона представляє собою лінійний стек шарів. Створення моделі зводиться до послідовного додавання шарів один за одним.

Основні кроки створення та навчання моделі в Keras:

1.  Визначення архітектури: Створити екземпляр Sequential та додати до нього шари (layers). Найпоширеніший шар – Dense (повнозв'язний), де кожен нейрон одного шару з'єднаний з усіма нейронами наступного.

2.  Компіляція моделі: За допомогою методу compile() налаштувати процес навчання, вказавши:

- optimizer: алгоритм, який буде оновлювати ваги (напр., 'adam'). Його мета – мінімізувати функцію втрат.

- loss: функцію втрат, яку потрібно мінімізувати (напр., 'binary_crossentropy' для двох класів).

- metrics: метрики для відстеження якості навчання (напр., \['accuracy'\]).

1.  Навчання моделі: Викликати метод fit(), передавши йому навчальні дані (X_train, y_train), кількість епох (epochs) та розмір батча (batch_size).

2.  Оцінка та прогнозування: Використовувати методи evaluate() та predict() для оцінки якості моделі та отримання прогнозів.

## Практична частина

Ми створимо та навчимо мережу розв'язувати задачу бінарної класифікації на згенерованих даних, які неможливо розділити однією прямою лінією.

Крок 1: Імпорт бібліотек та генерація даних

1.  Створіть новий ноутбук Lab3_MyName.ipynb.

2.  Імпортуйте необхідні бібліотеки:

```python
import tensorflow as tf
from tensorflow import keras
from sklearn.datasets import make_circles
import matplotlib.pyplot as plt
import numpy as np
```

3.  Згенеруємо набір даних "два кола" та візуалізуємо його.

```python
X, y = make_circles(n_samples=1000, noise=0.05, factor=0.5, random_state=42)

plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], c=y, cmap=plt.cm.RdBu)
plt.title("Згенеровані дані для класифікації")
plt.xlabel("Ознака 1")
plt.ylabel("Ознака 2")
plt.show()

Крок 2: Створення архітектури моделі
```

1.  Створіть Sequential модель.

2.  Додайте шари. Ми використаємо один [[courses/neural-networks/glossary/prykhovanyi-shar|прихований шар]] з 4 нейронами та активацією [[courses/neural-networks/glossary/relu|relu]] і вихідний шар з одним нейроном та активацією sigmoid, оскільки це задача бінарної класифікації.

```python
model = keras.Sequential([
    # Вхідний шар має 2 ознаки (input_shape=(2,))
    # Прихований шар з 4 нейронами та функцією активації ReLU
    keras.layers.Dense(4, activation='relu', input_shape=(2,)),
    # Вихідний шар з 1 нейроном та активацією sigmoid
    # (для отримання ймовірності належності до класу 1)
    keras.layers.Dense(1, activation='sigmoid')
])
```

Крок 3: Компіляція та аналіз моделі

1.  Скомпілюйте модель, вказавши оптимізатор, функцію втрат та метрику.

```python
model.compile(optimizer='adam',
              loss='binary_crossentropy',
              metrics=['accuracy'])
```

2.  Виведіть структуру моделі, щоб проаналізувати кількість шарів, нейронів та параметрів (ваг), що будуть навчатися.

```python
model.summary()
```

Крок 4: Навчання моделі

1.  Запустіть процес навчання на 100 епохах. verbose=0 вимикає логування процесу для кожної епохи.

```python
# Навчаємо модель на наших даних
history = model.fit(X, y, epochs=100, verbose=0)

Крок 5: Оцінка результатів
```

1.  Оцініть фінальну точність моделі на тих самих даних, на яких вона навчалася.

```python
loss, accuracy = model.evaluate(X, y)
print(f"\nПідсумкова точність моделі: {accuracy*100:.2f}%")

Візуалізуйте історію навчання (зміну функції втрат та точності з кожною епохою), щоб побачити, як модель покращувала свої результати.

# Відображаємо історію навчання
plt.figure(figsize=(10, 5))
```
