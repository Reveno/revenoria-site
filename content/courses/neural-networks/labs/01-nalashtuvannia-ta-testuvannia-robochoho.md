# Налаштування та тестування робочого середовища Google Colaboratory

> [!abstract] Пов'язана лекція
> [[courses/neural-networks/lectures/02-osnovy-shtuchnykh-neironnykh-merezh|Лекція 2. Основи штучних нейронних мереж]]

## Професійні компетентності

Після виконання лабораторної роботи здобувач освіти повинен навчитися створювати та налаштовувати ноутбуки, працювати з текстовими та кодовими комірками, використовувати файлову систему; отримати навички встановлення зовнішніх бібліотек, підключення Google Диска для постійного зберігання даних та активації апаратних прискорювачів (GPU) для ресурсомістких обчислень.

В ході виконання лабораторної роботи здобувачі передвищої фахової освіти повинні набути наступні програмні компетентності:

- СК01. Здатність алгоритмічно та логічно мислити.

- СК07. Здатність розробляти модулі і компоненти програмного забезпечення за допомогою типових алгоритмів та інструментів.

## Перелік необхідного обладнання та програмного забезпечення

- Персональний комп'ютер з операційною системою (Windows, Linux або macOS).

- Вебпереглядач для доступу до онлайн-ресурсів.

- Стабільне підключення до мережі Інтернет.

## Теоретична частина

Google Colaboratory (скорочено Colab) — це безкоштовне хмарне середовище, що базується на Jupyter Notebook і дозволяє писати та виконувати код на Python безпосередньо у браузері.

Ключові переваги Google Colab:

- Нульове налаштування: Вам не потрібно встановлювати Python, Jupyter або бібліотеки на свій комп'ютер. Все працює "з коробки" через браузер.

- Безкоштовний доступ до GPU та TPU: Colab надає вільний доступ до графічних (GPU) та тензорних (TPU) процесорів, що є критично важливим для глибокого навчання та інших складних обчислень.

- Інтеграція з екосистемою Google: Ноутбуки зберігаються на вашому Google Диску, що дозволяє легко ділитися ними, коментувати та працювати спільно, як у Google Docs.

- Попередньо встановлені бібліотеки: Більшість популярних бібліотек для аналізу даних та машинного навчання (NumPy, Pandas, Matplotlib, Scikit-learn, TensorFlow, PyTorch) вже встановлені та готові до використання.

Огляд інтерфейсу

Інтерфейс Colab інтуїтивно зрозумілий і складається з кількох основних частин:

1.  Меню: Стандартне меню (Файл, Редагування, Вигляд, Вставка, Середовище виконання, Інструменти, Довідка), де знаходяться всі основні дії з ноутбуком.

2.  Панель інструментів: Кнопки для швидкого додавання кодових (+ Code) або текстових (+ Text) комірок.

3.  Комірки (Cells): Основні будівельні блоки ноутбука.

    - Кодові комірки: Місце для написання та виконання коду на Python.

    - Текстові комірки: Підтримують форматування Markdown для створення заголовків, списків, вставки зображень, посилань та формул.

4.  Ліва бічна панель: Містить корисні інструменти:

    - Зміст: Автоматично створює навігацію по заголовках вашого ноутбука.

    - Фрагменти коду: Готові приклади коду для типових завдань.

    - Файли: Доступ до тимчасової файлової системи віртуальної машини та можливість підключення Google Диска.

## Практична частина

Крок 1: Створення першого ноутбука

1.  Перейдіть на сайт Google Colab: [colab.research.google.com](https://colab.research.google.com).

2.  Увійдіть у свій Google-акаунт.

3.  У вікні, що з'явиться, натисніть New notebook (Новий блокнот) або перейдіть через меню File -\> New notebook.

4.  Новий ноутбук буде створено та збережено у вашому Google Диску в папці Colab Notebooks.

5.  Клацніть на назву файлу (за замовчуванням UntitledX.ipynb) у верхньому лівому куті та перейменуйте його на Lab1_MyName.ipynb.

Крок 2: Робота з комірками

1.  Текстова комірка: Натисніть кнопку + Text. У комірці, що з'явилася, введіть заголовок, використовуючи синтаксис Markdown. Наприклад:\
    \# Лабораторна робота №1\
    \*\*Виконав(ла):\*\* \*Прізвище І.П.\*\
    \*\*Група:\*\* \*Назва групи\*\
    \
    Щоб побачити відформатований результат, клацніть за межами комірки або натисніть Shift+Enter.

2.  Кодова комірка: За замовчуванням перша комірка є кодовою. Введіть туди простий код на Python:\
    message = "Привіт, Colab!"\
    print(message)

3.  Виконання коду: Щоб виконати код, натисніть на іконку "Play" ліворуч від комірки або скористайтеся комбінаціями клавіш:

    - Ctrl+Enter: виконати поточну комірку.

    - Shift+Enter: виконати поточну комірку та перейти до наступної (або створити нову).\
      При першому запуску підключення до віртуальної машини може зайняти кілька секунд.

Крок 3: Встановлення та імпорт бібліотек

Більшість бібліотек вже встановлені. Давайте перевіримо версію NumPy.

1.  Створіть нову кодову комірку та виконайте:\
    import numpy as np\
    print(f"Версія NumPy: {np.\_\_version\_\_}")

2.  Щоб встановити бібліотеку, якої немає, використовується команда pip, перед якою ставиться знак оклику !. Давайте встановимо бібліотеку cowsay для розваги:\
    !pip install cowsay

3.  Після встановлення її можна імпортувати та використовувати:\
    import cowsay\
    cowsay.cow("Я вмію встановлювати бібліотеки в Colab!")

Крок 4: Робота з файловою системою

1.  Перейдіть на ліву бічну панель та відкрийте вкладку Files (іконка папки). Ви побачите тимчасову файлову систему віртуальної машини.

2.  Створимо файл програмно. Виконайте наступний код:\
    with open("my_file.txt", "w") as f:\
    f.write("Це тимчасовий файл. Він зникне після завершення сесії.")

3.  Натисніть кнопку Refresh (Оновити) на панелі файлів, і ви побачите my_file.txt.

4.  Важливо: Файли в цій системі є тимчасовими і будуть видалені після закриття ноутбука та завершення сесії.

Крок 5: Підключення (монтування) Google Диска

Щоб зберігати файли на постійній основі, потрібно підключити ваш Google Диск.

1.  Натисніть на іконку Mount Drive (Підключити Диск) на панелі файлів.

2.  У кодовій комірці, що з'явиться, виконайте код:\
    from google.colab import drive\
    drive.mount('/content/drive')

3.  Перейдіть за посиланням, що з'явиться у виводі, виберіть свій акаунт, скопіюйте код авторизації, вставте його у поле вводу в Colab і натисніть Enter.

4.  Після успішного монтування на панелі файлів з'явиться папка drive, яка є вашим Google Диском. Тепер ви можете читати та записувати файли безпосередньо на нього.

5.  Давайте створимо файл на вашому диску:\
    \# Шлях /content/drive/MyDrive/ є стандартним шляхом до кореня вашого диска\
    with open("/content/drive/MyDrive/permanent_file.txt", "w") as f:\
    f.write("Цей файл збережено на моєму Google Диску!")\
    \
    Перевірте свій Google Диск — цей файл має з'явитись там.

Крок 6: Використання апаратних прискорювачів (GPU)

1.  Перейдіть в меню Runtime -\> Change runtime type (Середовище виконання -\> Змінити тип середовища виконання).

2.  У вікні, що відкрилося, в полі Hardware accelerator (Апаратний прискорювач) виберіть T4 GPU. Натисніть Save.

3.  Увага: Зміна середовища виконання перезапустить вашу віртуальну машину. Усі тимчасові файли та змінні будуть втрачені.

4.  Щоб перевірити, чи успішно підключився GPU, виконайте наступний код (використовує бібліотеку TensorFlow, яка встановлена в Colab):\
    import tensorflow as tf\
    try:\
    device_name = tf.test.gpu_device_name()\
    if device_name != '/device:GPU:0':\
    print('GPU не знайдено.')\
    else:\
    print(f'Знайдено GPU: {device_name}')\
    except Exception as e:\
    print(e)\
    \
    Якщо все налаштовано правильно, ви побачите повідомлення про знайдений GPU.

## Завдання для самостійної роботи

1.  Створіть новий ноутбук Lab1_Independent_Work.ipynb.

2.  Створіть текстову комірку з назвою роботи, вашим іменем та описом завдання.

3.  Підключіть ваш Google Диск.

4.  За допомогою коду (!mkdir) створіть на вашому Google Диску нову папку з назвою Colab_Independent_Data.\
    !mkdir -p /content/drive/MyDrive/Colab_Independent_Data

5.  Імпортуйте бібліотеку pandas та виведіть її версію. pandas — це потужна бібліотека для роботи з даними у вигляді таблиць.\
    import pandas as pd\
    print(f"Версія Pandas: {pd.\_\_version\_\_}")

6.  Створіть таблицю (DataFrame) з даними про студентів. DataFrame — це таблична структура, схожа на таблицю в Excel. Щоб її створити, ми спочатку створюємо "словник" Python з нашими даними, де ключі ('Ім\\я', 'Вік') стануть назвами стовпців.\
    \# 1. Створюємо словник з даними\
    student_data = {\
    'Ім\\я': \['Іван Петренко', 'Марія Сидоренко', 'Олег Ковальчук'\],\
    'Вік': \[20, 19, 21\],\
    'Оцінка': \[95, 88, 92\]\
    }\
    \
    \# 2. Створюємо DataFrame на основі словника\
    students_df = pd.DataFrame(student_data)\
    \
    \# 3. Виводимо DataFrame на екран, щоб перевірити\
    print("Створений DataFrame:")\
    print(students_df)

7.  Збережіть DataFrame у CSV-файл на вашому Google Диску. Щоб зберегти дані у форматі CSV (значення, розділені комами), використовується метод .to_csv(). Важливо правильно вказати шлях до папки, яку ви створили раніше. Параметр index=False потрібен, щоб не зберігати службові індекси рядків у файл.\
    \# Формуємо повний шлях до файлу на вашому Google Диску\
    file_path = '/content/drive/MyDrive/Colab_Independent_Data/students.csv'\
    \
    \# Зберігаємо DataFrame у CSV файл\
    students_df.to_csv(file_path, index=False)\
    \
    print(f"\nDataFrame успішно збережено у файл: {file_path}")

8.  Прочитайте дані з CSV-файлу назад у новий DataFrame. Тепер виконаємо зворотну операцію. Функція pd.read_csv() читає дані з файлу і створює з них нову таблицю.\
    \# Шлях до файлу, який ми щойно зберегли\
    file_to_read_path = '/content/drive/MyDrive/Colab_Independent_Data/students.csv'\
    \
    \# Читаємо дані з CSV у новий DataFrame\
    read_students_df = pd.read_csv(file_to_read_path)\
    \
    \# Виводимо вміст нового DataFrame на екран\
    print("\nDataFrame, прочитаний з файлу:")\
    print(read_students_df)
