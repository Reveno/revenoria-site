## Теоретична частина

Згорткові нейронні мережі (Convolutional Neural Networks, CNN) — це спеціалізований тип нейронних мереж, розроблений для ефективної роботи з даними, що мають сіткову структуру, наприклад, із зображеннями. На відміну від повнозв'язних мереж, які "втрачають" просторову інформацію, перетворюючи зображення на вектор, CNN обробляють дані у їхній вихідній 2D-формі.

Основні шари CNN:

1.  [[courses/neural-networks/glossary/zhortkovyi-shar|Згортковий шар]] (Convolutional Layer, Conv2D): Основний будівельний блок CNN. Він застосовує набір фільтрів (ядер) до вхідного зображення. Кожен фільтр є невеликою матрицею ваг (напр., 3x3), яка "ковзає" по всьому зображенню і виявляє певні патерни (краї, текстури, кути). Результатом роботи шару є набір карт ознак (feature maps).

2.  [[courses/neural-networks/glossary/shar-pidvybirky|Шар підвибірки]] (Pooling Layer, MaxPooling2D): Цей шар зменшує просторову розмірність карт ознак, залишаючи лише найважливішу інформацію. Найчастіше використовується Max Pooling, який ділить карту ознак на невеликі ділянки (напр., 2x2) і вибирає з кожної максимальне значення. Це робить модель стійкішою до невеликих зсувів об'єкта на зображенні та зменшує кількість обчислень.

3.  Повнозв'язний шар (Dense Layer): Після кількох згорткових та пулінгових шарів отримані карти ознак "випрямляються" у вектор за допомогою шару Flatten і подаються на звичайні повнозв'язні шари для фінальної класифікації.

Типова архітектура CNN виглядає як послідовність блоків Conv2D -\> MaxPooling2D, за якими слідує Flatten та один або кілька Dense шарів.

## Практична частина

Ми знову будемо працювати з датасетом MNIST, але цього разу побудуємо CNN і порівняємо її точність з результатами попередньої роботи.

Крок 1: Завантаження та підготовка даних

1.  Створіть новий ноутбук Lab5_MyName.ipynb.

2.  Завантажте та нормалізуйте дані MNIST, як у попередній роботі.

3.  Важливо: для Conv2D шарів потрібно додати вимір каналу. Оскільки зображення чорно-білі, канал один. Змінимо форму даних з (кількість_зразків, 28, 28) на (кількість_зразків, 28, 28, 1).

```python
import tensorflow as tf

(x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data()
x_train, x_test = x_train / 255.0, x_test / 255.0

# Додаємо вимір каналу
x_train = x_train[..., tf.newaxis]
x_test = x_test[..., tf.newaxis]

print(f"Нова форма навчальних даних: {x_train.shape}")

Крок 2: Створення архітектури CNN моделі
```

1.  Створіть Sequential модель.

2.  Додайте згорткові, пулінгові та повнозв'язні шари.

```python
model_cnn = tf.keras.models.Sequential([
    # Вхідний шар очікує зображення 28x28 з 1 каналом
    # Згортковий шар: 32 фільтри розміром 3x3
    tf.keras.layers.Conv2D(32, (3,3), activation='relu', input_shape=(28, 28, 1)),
    # Шар підвибірки
    tf.keras.layers.MaxPooling2D((2, 2)),
    # Ще один згортковий блок для вивчення більш складних патернів
    tf.keras.layers.Conv2D(64, (3,3), activation='relu'),
    tf.keras.layers.MaxPooling2D((2, 2)),
    # "Випрямлення" даних для повнозв'язного шару
    tf.keras.layers.Flatten(),
    # Повнозв'язні шари для класифікації
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(10, activation='softmax')
])

model_cnn.summary()

Крок 3: Компіляція та навчання
```

1.  Скомпілюйте модель аналогічно до попередньої роботи.

> model_cnn.compile(optimizer='adam',\
>                   loss='sparse_categorical_crossentropy',\
>                   metrics=\['accuracy'\])

2.  Навчіть модель. Процес може зайняти трохи більше часу, оскільки обчислень більше. Рекомендується виконувати на GPU.

```python
history_cnn = model_cnn.fit(x_train, y_train, epochs=5, validation_data=(x_test, y_test))

Крок 4: Оцінка та порівняння
```

1.  Оцініть фінальну точність CNN на тестових даних.

```python
test_loss, test_acc = model_cnn.evaluate(x_test,  y_test, verbose=2)
print(f"\nТочність CNN на тестових даних: {test_acc*100:.2f}%")
```

2.  Порівняйте отриману точність з точністю повнозв'язної мережі з лабораторної роботи №4 (зазвичай вона складає ~97-98%). CNN, навіть проста, зазвичай досягає \>99% точності на MNIST. Зробіть висновок про ефективність CNN для задач комп'ютерного зору.
